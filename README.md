# Máquina em C e Assembly

Implementação de uma máquina computacional utilizando C e Assembly para fins acadêmicos.

## Objetivo

Explorar a interação entre linguagens de alto e baixo nível, compreendendo como instruções são executadas próximo ao hardware.

## Tecnologias

- C
- Assembly

## Conceitos Aplicados

- Arquitetura de Computadores
- Organização de Memória
- Registradores
- Instruções Assembly
- Integração C + Assembly
